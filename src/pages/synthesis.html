Reference · All method notes · Voicesaurus · Coverage & remaining techniques · Rust / CPAL / CLAP

Synthesis creates a playable sound from notes, excitation or stored samples. Processing transforms incoming audio. An algorithm can serve either role: granular, spectral and filter techniques appear according to what each demonstration does. Built-in test signals let you hear processors before connecting an input.

Sample inputs: Original bass, electric-piano, plucked-string and synth loops (MIT); Karoryfer drums (CC0) and synthetic speech (MIT); CMU ARCTIC edited voice syllables; Oona Räisänen’s public-domain birdsong. An explicit Input choice stays selected across processor presets; choose Preset input to follow each demonstration’s signal.
