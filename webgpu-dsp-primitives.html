PORTING CHECKLIST Reduce large time values before phase math so f32 precision stays musical. Translate GLSL modulo, two-argument arctangent, casts, and shifts explicitly. Nyquist-cull additive modes; smooth-looking formulas are not automatically band-limited. Workgroup barriers are local. Ordered feedback, cross-group reductions, and stream state need passes or scans. Portable core WGSL has integer—not floating-point—atomic accumulation; prefer gather and staged reductions.

Shader audio architecture

GPU audio combines sample-parallel kernels, block state, reductions, and streamed output.

  • Sample-parallel kernelsout[n] = synth(f32(n) / sampleRate)Stateless oscillators, envelopes, waveshapers, and feed-forward filters can calculate each output sample independently.
  • Recursive statey[n] = x[n] + feedback * y[n - delay]IIR filters, feedback delays, waveguides, envelope followers, and compressors carry results from earlier samples into later ones.
  • Workgroup synchronizationvar<workgroup> tile: array<f32, N>; workgroupBarrier();Shared memory and barriers coordinate one workgroup. Larger FFTs, scans, and reductions cross workgroup boundaries through additional compute passes.
  • Parallel reductionmix[n] = sum(voices[0..voiceCount, n])Voice-, grain-, partial-, mode-, and bin-parallel kernels produce many values that converge into fewer audio channels through tree or staged sums.
  • Aliasing controlsaw = rawSaw - polyBlep(phase, hz / sampleRate)Discontinuities and nonlinear processing create frequencies above Nyquist. Polynomial edge correction, partial culling, band-limited tables, filtering, and oversampling limit foldback.
  • Frequency and phasephase[n] = phase0 + prefixSum(frequency / sampleRate)Pitch trajectories become oscillator phase through integration. Directly multiplying time by a changing frequency produces a different instantaneous pitch.
  • Floating-point timelocalTime = f32(n - chunkStart) / sampleRateChunk-local and note-local coordinates preserve finer f32 resolution than an ever-growing absolute timer.
  • Buffer accesssample = audioBuffer[base + stride * index]Sequential history and tiled FIR reads have coherent memory access. Granular playheads, spatial taps, and large lookup fields create scattered gathers.
  • Browser audio streamingcompute → staging ring → AudioWorkletWebGPU produces PCM buffers while Web Audio owns the playback deadline. Buffer rings overlap GPU rendering, CPU-visible transfer, and audio-device consumption.
  • Optional GPU featuressubgroups ? fastReduction() : workgroupReduction()Subgroups and shader-f16 can accelerate reductions and neural kernels, but adapter support and subgroup width vary.
  • Two-dimensional dispatchgid = vec2(sampleIndex, voiceIndex)Large workloads can span both time and synthesis entities such as voices, modes, grains, sources, output channels, or candidate patches.
  • Morphazoid's current pipelinedry pass → history buffer → FX pass → vec2<f32> PCMThe live synth submits two compute passes and reads stereo chunks for scheduled playback. Its default generated chunk represents 100 ms of audio.
