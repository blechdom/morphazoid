    Help & device limits

    Line inputs and USB interfaces use the browser’s “microphone” permission too. Stereo requires two capture channels; device details show what was provided. Nothing is uploaded.

    Surround tests use discrete outputs, not simulated surround. Configure your interface in system sound settings first. 5.1 order: L, R, C, LFE, rear L, rear R; 7.1 adds side L/R. Verify the physical wiring. The sub test uses 80 Hz.

    Output selection is shared with compatible instruments. Input device, channels and echo cancellation apply to L-system Delay, Graph Delay, Sandy Syrup and Candy Coil. Each effect keeps its own gain.

    Opening a menu does not start a device. Closing one keeps its connection active, but mutes live input monitoring. Stop all or Escape disconnects everything.

    Choices are saved on this browser. Audio, permissions and monitoring are never enabled automatically.
