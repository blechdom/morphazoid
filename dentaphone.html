Mode data

JSON · relative ratios

Ratio multiplies the fundamental; decay is T60 in seconds; gain is linear. Optional modeCount limits active rows; referenceStiffness and dispersion define the stiffness transform independently of presets. Pan runs from −1 to +1; strikeNode shapes position response, while strikeWeight supplies an explicit −1 to +1 input weight.

What is being modeled?

Each tooth retunes the selected Dentaphone resonator: every partial keeps its own frequency, T60, amplitude, excitation node, and pickup weight. The default 2D view maps all 32 crown regions directly to the illustrated dental plates for tooth playing and brushing. The optional 3D tab uses MakeHuman's complete CC0 dentition, separated into 32 selectable tooth meshes and two animated jaw hinges; both views share the same notes, materials, tooth vibration, and toothbrush, while 3D adds jaw motion, chomping, and food patterns.
