Steps to train the CNN Network for Advance Prediction


1. Open MATLAB version 2020b or later

2. Make the current folder- "Audio Files and MatLab Code Used for Advance Prediction of CHF"
   as working directory 

3. Run the "CNN_TRAINING_CODE_FOR_ADVANCE_PREDICTION_OF_BOILING_CRISIS.m" file to get the trained    network

Note : The network resulted from following steps 1 to 3, is for "Advance Prediction" as discussed in          the original manuscript.

Steps to train the CNN Network for Boiling Regime Prediction

- Follow steps 1 and 2 as mentioned above.

- Move all the audio files in "Pre-CHF" folder to "NB" folder

- Run the "CNN_TRAINING_CODE_FOR_BOILING_REGIME_PREDICTION.m" file to get the trained network
