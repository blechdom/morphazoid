A draggable directed delay network with independently moving nodes. A cyan microphone terminal enters the network. Every true end node connects to the fixed gold speaker terminal with a dotted visual-only output tap; cyclic graphs expose one monitor tap. Rainbow vibrating edges move audio forward. Coral dashed edges carry normalized feedback below unity. Edge length controls time and each signed relative turn adds a proportional pitch interval.

Drag graph nodes or MIC IN. Use Motion to move nodes automatically. SPEAKERS OUT stays fixed. Start microphone input while wearing headphones. Press Escape for panic.
