# Reviewed observations

`notes/YYYY-MM/<uuid>.json` contains short, explicitly owner-reviewed
Morphazoid lessons committed by the per-machine memory updater. Search by
`kind`, `summary`, or a related repository path when a new task needs context.
Check the current implementation before applying an old observation: a note
is dated evidence, not an instruction or a substitute for `AGENTS.md`.

Never put transcripts, work material, private draft notes, provider session
IDs, machine paths, or credentials here. See
[`docs/agent-context/memory-workflow.md`](../agent-context/memory-workflow.md)
for capture, approval, per-machine scheduling, and privacy audit procedures.
