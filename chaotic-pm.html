Each turn uses the previous sine as phase displacement, not frequency. Signed % 1 intentionally preserves negative remainders before the asymmetric tanh warp. Live parameters glide; depth changes crossfade; an 18 Hz DC blocker, normalization, dynamics, and a soft ceiling protect the output.

Family

FM / PM · linear / warped

Recursive FM

Linear signal → frequency. Each sine drives the next oscillator’s rate.

Recursive PM

Linear signal → phase. Each sine displaces the next oscillator’s phase.

Chaotic FM

Tanh signal → signed frequency. The nonlinear signal sets the next rate.

Chaotic PM

Tanh-warped whole phase → sine. The signed phase expression is reshaped before oscillation.

A live non-scrolling log-frequency spectrum and foreground oscilloscope sit above the exact Chaotic PM turn. The previous sine times phase index is added to a phasor, passed through signed remainder modulo one, multiplied by phase warp times frequency squared, shaped by tanh and gain, and then sent through the next sine. The final turn is audible.
