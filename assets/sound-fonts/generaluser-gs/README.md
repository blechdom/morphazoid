The creator's changelog identifies this as version 2.0.3, released February 22,
2026. The file's internal name still includes `BETA`; that upstream metadata is
preserved. There are 261 melodic presets, 13 GS drum presets at bank 128, and
13 additional XG mappings of those kits at bank 120: 287 preset records total.
Each of the 128 General MIDI programs is present at bank 0.

The GeneralUser GS License v2.0 permits private/commercial music creation,
software integration, modification and redistribution. It also explains the
author's uncertainty about the historical origins of some samples. The full
license is retained verbatim; this notice does not replace its terms.

GeneralUser uses SoundFont generators and modulators extensively. Playback
requires a complete SoundFont engine; its author lists SpessaSynth among the
supported engines. The asset is shared through `../catalog.json` for any
Morphazoid instrument that loads SoundFonts.

Exact source URLs, file sizes, license hashes and asset hashes are in
[`../provenance.json`](../provenance.json).
