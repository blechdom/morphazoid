# FluidR3Mono GM 2.312

The complete, unmodified SF3 distributed with MuseScore 2.1.0, from its official
repository tag `v2.1.0` (commit `0a623fc7429519bb4779c64f2e3b9e3709476003`).

- Original FluidR3: Frank Wen, copyright 2000–2002 and 2008.
- Mono conversion: Michael Cowgill, copyright 2014–2016.
- Temple Blocks: Ethan Winer, copyright 2002.
- Drumline Percussion: Michael Schorsch, copyright 2016.

[Official release files](https://github.com/musescore/MuseScore/tree/v2.1.0/share/sound)
include the [complete MIT license and acknowledgements](LICENSE.md), copied
verbatim here with their original text encoding and line endings. Include these
copyright and permission notices with redistributed copies and derivative works.

This release has 195 presets (160 melodic and 35 percussion), all 128 bank-0
General MIDI programs, and 1,037 compressed samples. SF3 uses lossy Ogg Vorbis
sample compression and requires an SF3-capable player. The Temple Blocks and
marching percussion presets intentionally map only selected keys; their catalog
preview notes address playable keys.

The SoundFont contains a stale embedded comment saying `DO NOT REDISTRIBUTE ANY
OF THESE SAMPLES`. The same official release's accompanying license explicitly
publishes this mono bank under MIT, with permission to use, copy, modify and
distribute it. Both the original asset and the accompanying license are retained
without alteration, so this discrepancy remains visible.

The shared catalog is `../catalog.json`; exact upstream URLs, sizes and SHA-256
hashes are recorded in [`../provenance.json`](../provenance.json).
