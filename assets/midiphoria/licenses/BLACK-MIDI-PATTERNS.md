# Reusable Black MIDI Patterns and Phrases

This is a library of note arrangements/art packed in different formats for MIDI editors commonly used by blackers 🤓🤓🤓

## Formats
- Domino Part File (.dmp)
- FL Studio Score File (.fsc)
- MIDI File (.mid)

## Usage
- Clone or download the repository
- Symlink or copy folder to editor's search directory
- Import pattern to project
- (end) 

There are convenient ways to browse the patterns in your editor of choice.

### Domino
- Bind `Import events...` to a hot key combo

![image](/meta/images/domino_bind.png)

- Press the new combo, and register the folder `\domino_dmp\Black MIDI` for easy preview and selection

![image](/meta/images/domino_import-window.png)

- K.O.!

### FL Studio
- Create symlink of `\fl-studio_fsc\Black MIDI` into `%userprofile%\Documents\Image-Line\FL Studio\Presets\Scores`. (or just copy it)

![image](/meta/images/fl-studio_score-folder-symlink.png)

- In FL Studio, enable the browser (on the edge of left side)
- Find `Scores` > `Black MIDI`

![image](/meta/images/fl-studio_browser.png)

- Drag and drop any pattern into a newly created MIDI Out track. (It wipes out the entire track)

![image](/meta/images/fl-studio_drag-n-drop-pattern.png)

- Select all of the placed notes and copy paste into desired location
- You are now blessed by Allah

## Contributing

This pack is sort of like a standard library. When adding your own pattern to this pack, the pattern must meet the guidelines:

- You must be the creator of the pattern.

- You must allow the public to use and modify the pattern into their works in any way desired with no special conditions.

- The pattern must be named with alphanumerical characters only, with the special inclusion of brackets `[` `]`, period `.`, tilde `~`, minus `-`, plus `+`, and underscore `_`  characters.

- Slight deviation of similar or existing patterns are allowed as long as it is properly categorized and named with at least three underscores `_` with words around it.

- MIDI files and Domino part files must be exported at 960 PPQ.

For the structure of the folders, let's keep the familiar positioning of the patterns in browsing view by granularly categorizing the patterns. `X beats\Commons` in particular should have a rather static amount of folders. Nest as much folder as you could (but not as much how you nest an .xz archive)
