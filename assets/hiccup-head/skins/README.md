# Hiccup Head visual skin assets

These three 4×4 component sheets were generated as original project assets with OpenAI ImageGen on 2026-09-03. They contain a clean head plus separate eyes, brow, nose, lips, tongue, tooth, ears, hair, hand, kiss, brush, tether, and material swatch. No external photographs or third-party artwork are embedded.

- `cut-paper-collage.webp`: torn vintage-magazine paper, halftone grain, and mismatched photographic cutouts.
- `portrait-1904.webp`: a fictional, non-identifiable 1904 studio-photograph treatment with monochrome grain and scratches.
- `pantry-portrait.webp`: an original food-composite portrait made from cabbage, onion, tomato, green pepper, pasta, mushroom, berries, and carrot.

The generated PNG masters are intentionally not shipped. The runtime component sheets are 1024×1024 alpha WebP files and are loaded only when their visual skin is selected.

`vintage-magazine-face-fields.webp` is a separate original project asset generated with OpenAI ImageGen on 2026-09-03. It is an opaque 1536×1024 WebP arranged as a 3×2 atlas of six 512×512 beat-selectable face fields, in row-major order:

1. Turquoise stand mixer: `(0, 0, 512, 512)`
2. Red hibiscus: `(512, 0, 512, 512)`
3. Chrome automobile tail light: `(1024, 0, 512, 512)`
4. Blue patterned fabric and belt: `(0, 512, 512, 512)`
5. Citrus market display: `(512, 512, 512, 512)`
6. Magenta carnival lights: `(1024, 512, 512, 512)`

The six fields are synthetic vintage-magazine collage imagery; no external photographs or third-party artwork are embedded.

`wild-ink-decay-fields.webp` is an original project texture atlas generated with OpenAI ImageGen on 2026-09-03. It is an opaque 2048×512 WebP arranged as four square photographic fields in one row: fictional theatrical blood, viscera, a maggot colony, and plain cheese-and-pepperoni pizza. Zombie Zoid selects one cell deterministically from the scheduled step; it contains no people, identifying imagery, text, or third-party artwork.
