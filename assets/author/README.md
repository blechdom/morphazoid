# Author artwork

`kristin-galvin.webp` was generated on 2026-09-13 with the built-in OpenAI
image-generation tool, using Kristin Galvin's public GitHub profile portrait as
the identity reference.

The final prompt requested a weird but affectionate fifty-year-old
cyber-acoustics professor and mad-scientist musician. It preserves the
portrait's long side-parted hair, translucent angular glasses, sideways glance,
and mischievous half-smile while adding mature facial structure, windblown
patch-cable hair, oscilloscope lenses, antenna coils, a synth-knob earring, and
a crooked cybernetic collar. It requested a tactile enamel, metal, glass,
glowing-wire, and brass finish; cyan, coral, violet, lime, and amber highlights;
a compact silhouette readable at 64 pixels; and a flat black background. It
explicitly excluded youthful doll proportions, text, borders, badges, scenery,
watermarks, cropping, and cruel or grotesque exaggeration.

The generated square source was converted to a 512 × 512 WebP at quality 90.
