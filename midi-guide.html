MIDI & WAX Plugin Guide

Play Morphazoid from a controller in the browser, or load it in your DAW with WAX, an audio plug-in that puts a browser inside a VST3 or Audio Unit.

Browser MIDI

Start playing

  1. Open any playable instrument and select MIDI in its top bar.
  2. Click once to let the browser request access to your connected devices.
  3. Watch the receive light flash for incoming notes and controls.
  4. Use the L/R meter to see the two channels reaching the audio destination; panning and channel imbalance stay visible.

Hover or click the gear at the top right to update audio and MIDI settings while keeping the instrument open behind it. The bottom Full I/O setup ↗ link opens a separate tab for speaker-by-speaker surround checks, microphone levels and monitoring, and a spoken “MIDI received” check.

Choose input and output

Audio Out, Mic / Audio In, MIDI In, MIDI Out, and MIDI Map describe the routes available to the current instrument. A greyed-out selector means that route is not used by the instrument or cannot be selected in this browser. Microphone permission and stream controls remain on instruments that use live input; some browsers expose only the system audio destination.

Computer keys

This is the default MIDI Map. Melodic instruments use Z S X D C V G B H N J M for C3–B3 and Q 2 W 3 E R 5 T 6 Y 7 U for C4–B4.

Drum instruments use the 4 × 4 pad rows 1 2 3 4, Q W E R, A S D F, and Z X C V. [ and ] shift octaves; - and = change velocity. A few instruments retain their own typing or recording shortcuts instead.

Controller profiles

  • Automatic: Computer keys remains the default while connected hardware is detected automatically.
  • Morphazoid / NI: macro CC14–21. NI assignments require a user-created MIDI template.
  • Maschine Mikro: MIDI mode (Shift + Project), pads 36–51.
  • Akai MPK Mini: CC70–77, pads 36–51.
  • Arturia MiniLab 3: CC74, 71, 76, 77, 93, 18, 19, and 16; pads 36–43.
  • Novation Launchkey: Custom Mode CC21–28, pads 36–51.
  • Custom / Pass-through: leaves standard MIDI unchanged.

What gets mapped

  • Native maps: Chaotic and Recursive FM/PM, Shape, FM Drums, and Sample Drums use custom native mappings.
  • Universal maps: other pages use a conservative universal map: notes retune or trigger only where a safe target exists; matching CC labels control matching parameters; profile macro knobs address the first eight eligible sliders; Program Change selects presets where available.
  • Expression and time: pitch bend follows a mapped pitch, pressure seeks a matching pressure or intensity control, and MIDI Clock, Start, and Stop follow a page's tempo and transport when those controls exist.
  • Accepted messages: notes and velocity, pitch bend, CC, Program Change, polyphonic and channel pressure, MIDI Clock, Start, Continue, Stop, and Song Position. An instrument responds only when it has a useful mapping.

Browser MIDI Out

Input and output remain separate. In a normal browser, MIDI Out is a preview only: no output destination is exposed and none of the displayed values is sent. The separate I/O setup page can send one explicit test note to a selected output; this does not enable instrument MIDI routing.

The MIDI Out Monitor is diagnostic only. It separates exact instrument note previews, current controls as unassigned 0–127 CC candidates, genuine BPM clock candidates, and transport state; nothing it shows is routed, mapped, or sent as MIDI.

WAX in a DAW

What WAX is

WAX is the required audio plug-in host for Morphazoid in a DAW; it is not a standalone Morphazoid VST3 or Audio Unit. It loads browser pages as a VST3 on Windows or as a VST3 / Audio Unit on macOS, with host-aware audio, MIDI, transport, and saved state.

Get started

  1. Download AudioFusion WAX for Windows 10+ or macOS 11+.
  2. Install it, open your DAW, and rescan plug-ins.
  3. Insert the WAX role that matches what you want to make or process.
  4. Paste the hosted Chaotic FM page into WAX's address bar, or open the complete WAX-ready catalog.

WAX is currently published for Windows and macOS. On Linux, Morphazoid can be tested in a browser but not as an officially supported native WAX plug-in.

Pick the WAX role

WAX Instrument
Track MIDI → Morphazoid → audio. Use it for built-in synths, samplers, drums, and sonification.
WAX Audio FX
Track audio → Morphazoid processing → audio. Use it when Morphazoid should hear and process the DAW track.
WAX MIDI FX
MIDI or host clock → Morphazoid → MIDI. Use it to play another instrument from a MIDI-output page.

VST3 and Audio Unit are plug-in formats; Instrument, Audio FX, and MIDI FX are WAX routing roles. One WAX instance has fixed inputs and outputs, so replace its wrapper when the role changes.

Send MIDI to another instrument

  1. Insert WAX MIDI FX, then load Rubix or Algorithmic Sequencers.
  2. In the page's WAX panel choose MIDI only.
  3. Select a host MIDI destination, root note, division, channel, and gate.
  4. Place a software instrument after WAX, or route this track's MIDI to another instrument track.
  5. Start the DAW. Notes follow play, stop, BPM, position, seeks, and loops. Incoming MIDI is never echoed automatically.

Use a local copy

  1. Download the Morphazoid ZIP and extract it.
  2. Serve its dist-wax folder; do not open its HTML files directly. Direct files can block modules and AudioWorklets.
cd /path/to/morphazoid/dist-wax
python3 -m http.server 3436 --bind 127.0.0.1

Enter http://127.0.0.1:3436/ in WAX. On Windows PowerShell, use py -m http.server 3436 --bind 127.0.0.1 instead.

First check

  1. Open Chaotic FM in WAX Instrument, arm its track, and send MIDI notes.
  2. Confirm that WAX's Debug Panel sees audio and MIDI.
  3. Change a few controls, save and reopen the DAW project, then confirm state and audio remain intact.
  4. Test both 44.1 and 48 kHz before a serious session.
