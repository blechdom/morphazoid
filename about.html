About Morphazoid

Morphazoid is a collection of browser-based music instruments. The pages use geometry, recursive systems, mathematical curves, synthesis, microphone input, and recorded audio as control data for sound.

01

Basic operation

Each tool is a separate page with its own controls and audio state.

  1. Use the Tools menu to open an instrument. The page starts with audio off.
  2. Select Audio, Input, or the equivalent start control. Browsers require a user action before they allow a page to produce sound.
  3. Set the master or output level before starting dense textures, feedback, or a large number of voices.
  4. Start the page's playhead, reader, transport, or source. On geometry pages, visual motion and audio can usually be started and stopped independently.
  5. Use Reset all parameters, Reset, or the page-specific reset control to return to that page's initial settings.

Microphone pages request browser permission when input starts. Headphones reduce the risk of acoustic feedback. Pages with a file selector decode the selected file in the browser and use it as an instrument source.

02

Geometry Synths

These pages turn geometric contacts and intersections into continuous or triggered synthesis parameters.

Shape

Reads a two-dimensional contour with moving points, scan lines, or radial rays. Contact position, contour position, corner shape, and crossing angle can control pitch, level, stereo position, and timbre.

Lattice

Moves an editable isohedral tiling beneath a fixed reader line. Every edge intersection becomes a contact, so several voices can sound at the same time.

Spiral

Maps an isohedral tiling into log-polar space. Radius, angle, and multi-turn spiral readers intersect the warped edge field and send those contacts to the selected synthesis mode.

Solid

Intersects a three-dimensional wireframe with an oriented plane. Rotation, stretching, skew, and plane position change the intersection points and the sound mapped from them.

Hyper

Intersects a four-dimensional wireframe with a moving W hyperplane. Independent XW, YW, and ZW rotation changes which 4D segments cross the reader.

03

Geometry Drum Machines

These pages map geometry to the shared bank of sixteen synthesized percussion voices.

Shape Drum Machine

Converts contour contacts and corner events into drum triggers. Position, incidence, contour phase, and corner geometry determine voice selection and variation.

Lattice Drum Machine

Converts contacts between a reader and an isohedral lattice into drum events. Edge class, orientation, height, and incidence can select and retune voices.

Spiral Drum Machine

Maps contacts from an isohedral tiling transformed into log-polar space to the shared drum bank. Reader contacts follow the resulting radial and spiral geometry.

Solid Drum Machine

Maps intersections between a moving plane and a 3D wireframe to percussion. Wireframe motion and plane orientation determine the trigger pattern.

Hyper Drum Machine

Maps intersections between a W hyperplane and a rotating 4D wireframe to the drum bank. Four-dimensional position and rotation change the active voices.

04

Audio & Mic

These pages process a microphone, a local audio file, or a recorded loop.

Lumber

Records loops and displays them as rings. Each ring has direction, level, pan, mute, solo, filtering, pitch handles, playback heads, and optional shared delay.

L-mic

Sends live microphone input through recursive L-system descendants. Branch timing creates delay, accumulated turns create pitch shifts, and the tree shows both the full structure and the currently audible branches.

Graph Delay

Routes live microphone audio through a generated directed graph of delay nodes. Graph structure, traversal, pitch treatment, and feedback determine the signal paths.

Throatazoid

Runs microphone input, an internal glottal source, or both through one to seven vocal-tract models. Throats, tongues, noses, closures, and articulation controls change the tract response.

05

Fractals & Recursion

These instruments derive timing, pitch, or signal structure from recursive systems.

L-System

Expands turtle-drawing grammars and maps branch structure to sound. Iteration, branch timing, turn angle, length taper, and structure mode control the resulting voice tree.

Recursion

Contains the Fuzzy Donut recursive DSP instrument. It accepts generated noise, impulses, microphone capture, or a local file, then exposes the same audio process through manifold, time-spectrum, and routing views.

Julia

Traces the closed boundary of a Julia set and maps signed boundary turns to cyclic Shepard pitch motion. A self-similarity section compares related boundary arcs and provides several ways to hear their relationship.

06

Barber Shop Poles

These pages use staggered voices or read heads to create cyclic pitch and delay motion.

Shepard–Risset

Provides an octave-bank mode for continuous rising or falling pitch and a Morphisma sweep mode with quadratic frequency motion. Direction, speed, range, density, and stereo spread are adjustable.

Sandy Syrup Delay

Uses phase-staggered granular streams to process microphone or local-file audio. Sand presets hold grain rates; Syrup presets move them continuously.

Striped Sludge Delay

Uses multiple staggered delay heads that approach the source pitch at the center of each sweep, then move away in the opposite direction.

Candy Coil Delay

Uses phase-staggered variable-delay heads for repeated rising or falling pitch motion. Tap timing, ratio lock, head tilt, feedback, and dry/wet mix control the process.

07

Chaotic Synths

These pages build bounded oscillator systems from nested modulation or fractal sums.

Recursive FM

Nests frequency-modulation operators so each level drives the frequency of its child. Depth, carrier frequency, offset, modulation amount, and divisor are adjustable.

Recursive PM

Folds a sine carrier through a stack of recursive phase operators. Each deeper level contributes a reduced phase offset, and depth changes are crossfaded.

Chaotic FM

Passes oscillators through a nonlinear frequency-modulation cascade. A bounded hyperbolic-tangent stage limits each recursive signal before it drives the next oscillator.

Weierstrass

Builds a normalized sum of exponentially spaced oscillators. Wave mode sounds the sum directly; FM and phase-modulation modes use the same bank as a modulation trajectory.

08

Tools

These pages expose reusable sound design and geometry-analysis systems.

FM Drums

Edits the sixteen-voice percussion bank used by the geometry drum machines. The voices use FM and shaped noise rather than samples, and banks can be saved locally or copied as JSON.

Morphazoidical

Inspects the geometry features used for sound mapping. The workbench displays current form, contact, reader, and event values; the Feature Atlas defines the available fields.

09

Implementation

Morphazoid is a static web application. It does not require an application server at runtime.

Interface
Plain HTML, CSS, and JavaScript modules. There is no UI framework.
Graphics
Canvas renders the instrument stages. Display resolution is limited by a pixel budget on large or high-density screens.
Audio
Web Audio supplies oscillators, filters, routing, microphone input, decoding, and output. Continuous high-voice-count synthesis uses AudioWorklet processors.
State
Instrument pages load their baseline settings when opened. FM Drums can store an edited bank in browser-local storage.
Development
The repository provides a local static server with npm run dev and runs syntax checks and automated tests with npm run verify.
