Morphazoid

Morphazoid is a collection of browser-based audio experiments. Geometry, recursion, algorithms, and simulations generate sound; other experiments reshape live microphone input and existing audio files.

Start here

Basic operation

Every instrument keeps its own controls and audio state.

  1. Use the instrument pull-down to open an instrument. Audio starts off.
  2. Select the speaker to arm audio. On microphone instruments, start Input separately and grant microphone access only when the instrument asks.
  3. Set the output level before starting feedback, dense textures, or many voices.
  4. Start the playhead, reader, transport, or source. Many geometry pages let motion and audio run separately.
  5. Use the page's reset control to return to its default settings.

Microphone instruments ask for browser permission when input starts. Headphones help prevent feedback. File instruments decode the selected file locally in the browser.

Play and automate

MIDI Guide

The browser toolbar receives MIDI. WAX adds DAW-aware MIDI output on suitable pages.

Every playable instrument has a MIDI control in its top bar. Select MIDI to enable it; the browser requires a click before it can request access to connected devices. Its receive light flashes for incoming notes and controls. The small L/R meter shows the two channels being sent to the audio destination, so panning and channel imbalance stay visible. The gear at the far right opens the compact Morphazoid Settings panel.

Settings
Audio Out, Mic / Audio In, MIDI In, MIDI Out, and MIDI Map describe the routes available to the current instrument. A greyed-out selector means that route is not used by the instrument or cannot be selected in this browser. Microphone permission and stream controls remain on instruments that use live input; some browsers expose only the system audio destination. WAX receives audio and MIDI routing from its DAW or plug-in host.
Computer keys
This is the default MIDI Map. Melodic instruments use Z S X D C V G B H N J M for C3–B3 and Q 2 W 3 E R 5 T 6 Y 7 U for C4–B4. Drum instruments use the 4 × 4 pad rows 1 2 3 4, Q W E R, A S D F, and Z X C V. [ and ] shift octaves; - and = change velocity. A few instruments retain their own typing or recording shortcuts instead.
Controller profiles
Computer keys remains the default while connected hardware is detected automatically. Choose a named MIDI Map only to force one controller layout: Morphazoid and NI templates use macro CC14–21; Maschine Mikro uses MIDI mode (Shift + Project) and pads 36–51; Akai MPK Mini uses CC70–77 and pads 36–51; Arturia MiniLab 3 uses CC74, 71, 76, 77, 93, 18, 19, and 16 with pads 36–43; and Novation Launchkey uses Custom Mode CC21–28 with pads 36–51. Custom / Pass-through leaves standard MIDI unchanged. NI assignments require a user-created MIDI template rather than a factory mapping.
Mappings
Chaotic and Recursive FM/PM, Shape, FM Drums, and Sample Drums use custom native mappings. Other pages use a conservative universal map: notes retune or trigger sound only where a safe target exists, common CCs follow matching control labels, profile macro knobs address the first eight eligible sliders, and Program Change selects presets where available. Pitch bend follows a mapped pitch; pressure seeks a matching pressure or intensity control; and MIDI Clock, Start, and Stop follow a page's tempo and transport when those controls exist.
Messages
The shared input accepts notes and velocity, pitch bend, CC, Program Change, polyphonic and channel pressure, MIDI Clock, Start, Continue, Stop, and Song Position. An instrument responds only to messages that have a useful mapping on that page.
MIDI output
Input and output remain separate. In the normal browser, MIDI Out is currently a preview only: no output destination is exposed and none of the displayed values is sent. Suitable pages in the generated WAX build can run as MIDI FX, produce a deterministic companion sequence, and follow DAW tempo and position. Incoming MIDI is never echoed automatically.
MIDI Out Monitor
Output-capable browser instruments include a live monitor at the bottom of their control rail. It separates exact instrument note previews when that page publishes them, current controls as unassigned 0–127 CC candidates, genuine BPM clock candidates or other unmapped timebases, and transport state. The monitor is diagnostic only: nothing shown there is routed, mapped, or sent as MIDI yet.

Implementation

Morphazoid is a static site and does not need an application server.

Interface
Plain HTML, CSS, and JavaScript modules. No UI framework.
Graphics
Canvas draws the instrument stages with a pixel budget for large screens.
Audio
Web Audio handles synthesis, filters, routing, microphone input, decoding, and output. AudioWorklets handle continuous high-voice-count synthesis.
State
Pages load their defaults when opened. Instrument editors can keep selected banks in browser storage.
Development
Use npm run dev for the local server and npm run verify for checks and tests.
Plug-ins
Morphazoid for WAX — setup, routing, and Linux test notes.
