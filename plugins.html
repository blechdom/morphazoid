Release model

Separate instruments, shared system

Browser demo→ Shared DSP contract→ Individual DAW plug-in→ Optional collection bundle

Separate plug-ins keep automation lists short and let a saved project identify the exact algorithm it used. Common MIDI behavior, analyzer components, visual language, and release tooling are shared underneath.

Install guide

REAPER JSFX

One source file, no compiler or installer.

  1. In REAPER, choose Options → Show REAPER resource path.
  2. Open Effects and create a Morphazoid folder.
  3. Move the downloaded .jsfx file into that folder.
  4. Restart REAPER or refresh its FX browser.
  5. Add JS: Morphazoid: Chaotic FM to an instrument track.
Start with the track level low. Chaotic presets can redistribute energy quickly even though the output stage is bounded.

Version archive

Downloads never move

Every artifact has an instrument ID, plug-in version, format, checksum, and immutable URL. “Latest” is a catalog label—not a filename that silently changes underneath a saved project.

downloads/plugins/{instrument}/{version}/{format}/{file}

Browser demos and DAW builds can advance independently. Parameter IDs remain stable inside a plug-in line, while breaking changes require a new major version or a new instrument ID.
