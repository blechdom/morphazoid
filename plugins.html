Install

Add Chaotic FM to REAPER

  1. Download the file.
  2. In REAPER, choose Options → Show REAPER resource path. Put the file in Effects.
  3. Refresh the FX browser and add JS: Morphazoid: Chaotic FM.

No installer is needed. The current beta runs in REAPER 7 on macOS, Windows, and Linux.
