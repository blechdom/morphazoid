This asset is a real specimen photogrammetry reconstruction from Yuichi Kano's
ffish.asia / floraZia collection, not a generated or authored species model.
The published model is static and unrigged. Morphazoid's articulation, web,
contact constraints and performances are authored approximations.

Morphazoid derivative:
* All 106,200 animal triangles and the original UV coordinates are retained.
  The 12-triangle calibration cube and its separate texture were removed.
* The original 4096 x 4096 photographed color atlas was re-encoded as WebP,
  quality 92. Meshoptimizer compression is lossless for every mesh attribute;
  there is no mesh decimation or position quantization.
* The source has no supplied skeleton. Morphazoid authored 38 weighted joints:
  cephalothorax, abdomen, paired pedipalps/chelicerae and four grouped joints
  for each of the eight walking legs. Mouth-region skin boundaries and the
  grouped leg articulations are approximate. This is not a measured live
  animal gait, a recovered anatomical skeleton, or full collision simulation.
* Neutral inverse binds preserve the complete source surface. Procedural web
  contacts drive the same targets used by the instrument's sound engine;
  the viewer uses bounded inverse kinematics to bend the existing scan.
* Web geometry, lighting, the temporary caught-insect marker, and the rig are
  authored presentation. specimen.webp is rendered from this actual model
  and web, without a generated replacement image.
