Morphazoid modifications:
- Added 27 named rigid joints in an anatomical parent/child hierarchy.
- Parent parts carry their attached children when posed.
- Added a six-second Gentle joint demonstration with ten rotation channels.
- Original geometry, materials, image data, and rest pose are preserved.
- Runtime controls compose user pose offsets, 24 procedural routines and a
  sixteen-step per-joint score; embedded clips remain visual previews.
- Runtime-only bounded CCD calibration unfolds the curled legs into a neutral
  support stance and four gait corner poses. These angles are shared with the
  sound engine. The on-disk GLB, geometry and texture bytes remain unchanged.
- Neutral dark lighting, a ground surface, and self/ground shadows provide the
  current presentation. Stance, gait contacts and dances are authored
  approximations, not measured biomechanics.
- specimen.webp and ../instruments/roach-synth.webp are browser-rendered previews
  of this adapted model, resized for the page and catalogue.

This is a rigid part hierarchy, not a supplied professional deforming skeleton.
The original scan had separate parts but no animation rig. Contact-based pivot
centers were authored for this page. Leg-root, neck/pronotum, abdomen and wing
pivots are approximate. The source is a dried specimen with curled legs; its
motion demonstration is not a walking cycle or a biomechanical simulation.
Both wing covers share one mesh and move together. Each antenna remains one
rigid mesh. Large rotations may expose scan seams or intersect neighboring
parts. User controls deliberately allow exploratory poses.

Build and validation:
The source repository's scripts/build-roach-rig.py accepts the downloaded source
GLB and an output GLB path. It requires Python, numpy and scipy only during
asset preparation; none are browser runtime dependencies. The script preserves
all original geometry and texture bytes and verifies unchanged rest-pose world
transforms (maximum measured difference 1.11e-16).
See rig-manifest.json for per-joint pivot evidence, parent relationships,
confidence, suggested ranges and source/output hashes.

Example from the repository root:
python3 scripts/build-roach-rig.py /path/to/original-cockroach.glb assets/roach-synth/cockroach.glb

The earlier NiceModels product-preview images have been replaced by this
