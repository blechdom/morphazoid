# Graphonic Calculator — Desmos feature roadmap

A working list of Desmos graphing-calculator features the Graphonic Calculator does not have
yet, compiled on 2026-10-14 from the [research brief](graphonic-calculator-research.md)
(section numbers refer to it). Value and effort are first estimates; dependencies name the
code that must change first. Items are grouped by value, then by effort. The MVP already
covers expression entry and editing, explicit/implicit/polar/parametric curves, points,
shaded inequalities, sliders with bounce/loop/once animation and speeds, degree mode, the
pan/zoom viewport, hover readouts, local persistence, and the Points/Line/Radar readers with a
tempo control; see [graphonic-calculator.md](graphonic-calculator.md).
