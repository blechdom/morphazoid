How it works

The recording is never modified. Splices are markers on an intact loop, segments are the spans between them, and chords are alternative continuations drawn across the interior. Restore original loop removes every marker and you have exactly what you started with.

Without chords this is an ordinary loop and the order repeats every segment count. Add a chord and turn on Alternate, and that splice sends the reader one way then the other, so the order period grows. The number shown is measured by simulating the actual traversal, not asserted — an earlier design in this line was killed for displaying a count of 24 when the audible order period was 3.
