Physical model / math

Continuum: ρü = ∇·σ + fmuscle − cu̇, with near-incompressibility J = det F ≈ 1.

Real-time reduction: D(x,t) = Dhost(x) · [1 − qbodyG(x; μ,σ) − qtipGtip(x)], then A = D².

Tube scattering: ri = [Ai − Ai+1] / [Ai + Ai+1].

The full tongue is a nearly incompressible, actively stressed soft body. This instrument reduces it to moving Gaussian constrictions plus compensating shoulders, then recomputes every waveguide junction. It changes resonance and source loading; it does not change the animal's larynx, syrinx, membrane, or whistle source.

Thought experiment: a literal human tongue does not fit every skull. Geometry is normalized to the host tract. Human-on-bird, frog, reptile, and mouse combinations are deliberately speculative hybrids.
