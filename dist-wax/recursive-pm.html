Every recursion writes the previous sine into the next sine’s phase. At phase index 0—or after repeated index division—the result naturally approaches a plain sine. Depth changes crossfade, live parameters glide, and the output is normalized before a protective limiter.

A live, non-scrolling log-frequency spectrum uses rectangular level bars behind a bright oscilloscope trace. The complete recursive phase path shows every previous sine multiplied by its index and added to an independent phasor before the next sine operator.
