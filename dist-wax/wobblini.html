8 DECKS

Turn Audio on, then play a deck or Play all. The eight original demo loops are ready to go.

Load or drop an audio file onto any deck. Set its source BPM and set Cue on a beat, then turn on Sync. Deck 1 (the crown) leads the tempo and beat position. Speed changes pitch too.

Drag a record clockwise or backward to scratch. Release to resume its previous play state. Arrow keys move a focused record; Shift makes smaller movements. Records view keeps the master transport, tempo and crossfader above the platters; the deck editors stay hidden. The needle stays still while the record and full-file waveform rotate together. The dot on the waveform marks file position. Play/Pause stays in the center. Each gear opens that track’s controls. File loading is locked until you enable the upload control above the records. Switch views with the icons at the top.

Drag a waveform to seek. Set cue saves the current position; Cue returns there and pauses. The cue point is also beat zero for Sync. A beat loop starts at the current beat. Synced decks rejoin deck 1 after scratching. Manual speed changes release only that track from Sync. The loop markers show IN, OUT, and loop length.

In the mixer, Stereo shape moves all eight tracks together: left/right is pan, up/down is volume. Arrange an octagon, then move, rotate or stretch it; drag a numbered point to edit one track. Expand it for larger controls. Undo restores the last gesture.

Route decks to A or B to crossfade, or Thru to bypass it. Drag the wobble pad to bend every deck’s filter. Use its sliders for keyboard control.

All tiny keeps eight mini decks on screen; Edit opens one deck’s controls. Space toggles all decks. Keys 1–8 toggle individual decks when you’re outside a control.
